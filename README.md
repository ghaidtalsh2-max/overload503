## ⚡ فكرة اللعبة ورسالتها التعليمية
اللعبة تحاكي سيناريو هجوم حقيقي على خوادم الويب:
1. **أهمية الحدث:** أكثر من 70% من مواقع الويب تعمل بلغة PHP. الخلل يقع في محرك اللغة نفسه وليس في الكود البرمجي للتطبيقات.
2. **الثغرتان المحاكيتان:**
   - **CVE-2026-109618 (Multipart OOM Session Leak):** تدفق طلبات رفع ملفات خبيثة يسبب خطأ فادح في الذاكرة ويتخطى التنظيف ويسرب الذاكرة في كوكيز الجلسة.
   - **CVE-2026-109619 (OPcache Use-After-Free):** استخدام الذاكرة بعد تحريرها وارتباك الأنواع في ذاكرة OPcache المشتركة عبر مؤشر تالف (`0x7f3a`).
3. **الفخ والحاجة للترقية:** محاولة حل المشكلة بتحديث ووردبريس (`update wordpress`) تفشل وتخصم نقاطاً، والحل الجذري هو ترقية نواة PHP `sudo apt install php8.4=8.4.27` ثم التحقق `verify`.

## 🎮 الشاشات الست ومراحل اللعبة (Timeline Engine)

يعتمد النظام على ساعة زمنية موحدة (`roundStartAt`) تُبث لجميع الأجهزة دون أي تأخير أو حاجة لـ Cloud Functions:

1. **Screen 1 — LOBBY (45 ثانية):**
   - الحالة الطبيعية الهادئة الخضراء.
   - انضمام اللاعبين عبر الجوالات واختيار الكتل (WEB SENTINELS, AI NEURAL, DATA VAULT) بدون PIN.
2. **Screen 2 — THE BREACH (8 ثوانٍ):**
   - وميض أحمر، صافرات إنذار، وأشرطة هازارد متحركة.
   - قفزة الطلبات إلى 503 Service Unavailable وانهيار الذاكرة.
3. **Screen 3 — AUTHENTICATION (15 ثانية):**
   - شاشة تسجيل الدخول SSH وإدخال كلمة المرور المؤقتة المخفية نجومًا `Ov3r-503`.
   - ختم الوصول `ACCESS GRANTED` باللون الأخضر النيون.
4. **Screen 4 — STATION 1 (45 ثانية - Type to Block):**
   - هطول طلبات الهجوم على الشاشة الكبيرة.
   - حظر الطلبات بكتابة معرّف الطلب (مثل `block 4129` أو النقر على الرقاقات).
   - احتساب سرعة الطباعة الحقيقية (WPM) وسجل الحظر المباشر (Kill Feed).
5. **Screen 5 — STATION 2 (45 ثانية - Memory Pointer):**
   - رسم بياني حي للـ Heap Memory ومؤشر الذاكرة التالف `0x7f3a`.
   - تصفير المؤشر بكتابة `clear 0x7f3a` لتثبيت استقرار الخادم.
6. **STATION 3 — OPcache Poisoning (40 ثانية):**
   - كشف الصندوق المسموم `flag box-12` وتدوير الجلسات `rotate`.
7. **STATION 4 — Fix & Verification (45 ثانية):**
   - ترقية نواة PHP `sudo apt install php8.4=8.4.27` وتفادي فخ `update wordpress`.
   - فحص النظام بأمر `verify` لإتمام الاستعادة بنجاح.
8. **Screen 6 — HALL OF DEFENDERS (Secured):**
   - منصة التتويج وترتيب الفرق حسب متوسط النقاط.
   - الرتب السيبرانية: `ROOT`, `GUARDIAN`, `HUNTER`, `ANALYST`, `ROOKIE`.
   - بطاقة الجسر البحثي للتحويل إلى قراءة الورقة التقنية.

## 💻 قائمة الأوامر التفاعلية (Terminal Command Palette)

| الأمر | الوظيفة | التأثير في المحاكاة |
| :--- | :--- | :--- |
| `ssh` | بدء الدخول إلى الخادم | يطلب كلمة المرور المؤقتة `Ov3r-503` |
| `block <REQ_ID>` | حظر طلب خبيث هابط (مثل `block 4129`) | يخفض ضغط الذاكرة ويكسب +20 نقطة |
| `clear 0x7f3a` | تفريغ المؤشر التالف في الـ Heap | يصلح ثغرة الـ Use-After-Free |
| `flag box-12` | وسم الصندوق المسموم في الـ OPcache | كشف ارتباك الأنواع وإيقاف التسميم |
| `rotate` | تدوير جلسات المستخدمين المشبوهة | عزل كوكيز PHPSESSID المتسربة |
| `sudo apt install php8.4=8.4.27` | ترقية حزمة PHP للنواة الآمنة | ترقية الإصدار وحل الثغرات جذرياً |
| `verify` | فحص سلامة النظام والخدمات | التحقق من أمان الخادم وإتمام الاستعادة |
| `update wordpress` *(فخ تعليمي)* | محاولة تحديث التطبيق دون النواة | تحذير: خطأ! المشكلة في النواة (-10 نقاط) |
| `help` / `?` | استعراض الأوامر المتاحة | عرض تلميحات سياقية ذكية للمرحلة الحالية |

## 📱 التوافق والأجهزة المدعومة
- **شاشات العرض والبروجكتر (Host):** دقة 1280x800 فأعلى، مع وضع ملء الشاشة وأدوات تحكم طوارئ للمنظمين (Pause / Resume / Skip / Restart).
- **أجهزة الجوال (Mobile):** دعم متكامل لكيبورد الهواتف عبر `visualViewport` لمنع حجب سطر الأوامر، مع أزرار مساعدة (Chips) لتسريع الإدخال اللمسي (48px tap targets).
- **أجهزة اللابتوب (Laptop):** واجهة مقسمة لعمودين مع تركيز تلقائي دائم على سطر الأوامر الفعلي.
